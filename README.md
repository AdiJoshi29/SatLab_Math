# SatLab_Math
ADCS (Attitude Determination and Control Systems) Codes.

This is for SatLab, a cube-sat development team part of the Trident Labs student organization at Vishwakarma Institute of Technolgy, Pune.
This library was created by researching and solving the necessary equations for the appropriate sensors needed for a satellite to determine it position in orbit.
Primary sensor is the Sun Sensor. We will be using the sun to determine the satellite's attitude with respect to the earth.

This Repository Contains codes for the Following Sub-sections: Mathematics : Attitude Determination Mathematics Library

Sensor Fusion:

1. Sun Sensor
2. IMU-Accelerometer.
3. IMU-Gyroscope
4. IMU-Magnetometer
5. Kalman Filter
6. LPF
7. Orientation Calculations
8. Data Structure : Queue implemented via Linked Lists
